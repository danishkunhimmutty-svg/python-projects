# 🛒 E-commerce Purchases Analysis

## 📌 Project Overview
This project explores an e-commerce purchases dataset using Python. The objective is to perform exploratory data analysis (EDA) and answer business-related questions by using Pandas.

## 🎯 Objectives
- Load and explore the dataset.
- Calculate summary statistics.
- Filter data based on different conditions.
- Analyze customer purchasing behavior.
- Extract useful insights from customer information.

## 🛠️ Tools & Libraries
- Python
- Pandas
- Jupyter Notebook

## 📂 Dataset
The dataset contains information about customer purchases, including:
- Purchase Price
- Job
- Language
- Email
- Credit Card Provider
- Credit Card Expiry Date
- Purchase Time (AM/PM)
- Lot Number

## 📊 Analysis Performed
The notebook includes the following analyses:

- Displayed the first 10 records of the dataset.
- Explored dataset information and data types.
- Calculated:
  - Average purchase price
  - Maximum purchase price
  - Minimum purchase price
- Counted customers whose preferred language is English.
- Counted customers with the job title **Lawyer**.
- Compared AM vs PM purchases.
- Identified the top 5 most common job titles.
- Retrieved the purchase price for a specific lot number.
- Retrieved the email associated with a specific credit card number.
- Counted customers who used **American Express** and made purchases greater than **95**.
- Counted credit cards expiring in **2025**.
- Identified the top 5 most common email providers.
