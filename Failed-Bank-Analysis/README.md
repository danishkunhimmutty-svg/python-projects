# 🏦 FDIC Failed Banks Analysis

## 📌 Project Overview
This project demonstrates how to collect and analyze banking data directly from the FDIC website using Python. Instead of using a local dataset, the project retrieves HTML tables from the web with Pandas and performs exploratory data analysis (EDA).

## 🎯 Objectives
- Extract tabular data directly from a website.
- Explore and clean the retrieved data.
- Perform exploratory data analysis.
- Gain insights into failed banks data.

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## 🌐 Data Source
The data is imported directly from the FDIC website using Pandas.

**Method Used:**
- `pd.read_html()`

No local CSV or Excel dataset is required.

## 📊 Analysis Performed
- Imported HTML tables from the FDIC website.
- Explored the dataset structure.
- Renamed and formatted columns.
- Checked data types.
- Cleaned and organized the data.
- Performed exploratory data analysis using Pandas.

## 💡 Skills Demonstrated
- Web Data Extraction
- HTML Table Import
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Transformation
- Pandas Data Manipulation
